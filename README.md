# TravelOrbit MIS

Internal Management Information System and CRM for TravelOrbit.

## Stack

- Laravel 12 (PHP 8.3)
- PostgreSQL 16
- Livewire 3
- Bootstrap 5
- Redis
- Laravel Reverb

## Installation

```bash
composer install
npm install
php artisan key:generate
php artisan migrate
npm run build
```

## Development

```bash
npm run dev
php artisan serve
```
